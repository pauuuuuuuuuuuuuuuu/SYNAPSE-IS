# SYNAPSE-IS — Industrial Ecology & Waste-to-Value Exchange Platform

A high-performance, cyber-physical B2B Web Application dashboard interface designed for AI-driven industrial ecology, by-product circularity, and carbon accounting.

## 🚀 Key Modules Built

1. **Top KPI Telemetry**
   - **Circularity Index (88%)** with radial SVG arc gauge & +5.1% YoY gain.
   - **Waste Diverted (124.5 Tons)** with dynamic sparkline bars.
   - **Resource Utilization (92%)** with glowing spline chart.
   - **CO₂e Savings (3,140 kg)** with live operational status indicator.

2. **AI Graph Neural Network (Waste Stream Molecular Analysis)**
   - Fully interactive **Three.js 3D ball-and-stick model** of polymer by-product structures.
   - Draggable/rotatable atoms (Carbon, Hydrogen, Oxygen) with chemical purity tags and elemental percentages (`C: 72.4%`, `H: 18.2%`, `O: 9.4%`).

3. **Global Spatial Logistics Map (Reverse-Logistics)**
   - HTML5 Canvas real-time map with interactive geo-hubs (Rotterdam, Antwerp, Houston, Singapore, Shanghai, Santos).
   - Animated bezier curved transport routes with moving cargo packets and live tooltip inspection.

4. **Factory Digital Twin (Plant Alpha)**
   - Isometric **Three.js 3D simulation** of an advanced bio-refining & pyrolysis recycling facility.
   - Animated conveyor belt carrying material pallets, glowing reactor silos, fluid conduits, cybernetic grid, and switchable camera viewpoints (Isometric vs. Top-Down).

5. **Material Flow Analysis (Closed-Loop Sankey)**
   - SVG-based mass balance visualization from Raw (25%) & Recycled (75%) inputs to Catalytic Reactor (90%) and Production / Reuse streams.

6. **Automated ESG & Circular Carbon Ledger**
   - Chart.js AI optimization trajectory curves.
   - Blockchain-verified Carbon Credit trading ledger table (`#SYN-8842`, `#SYN-8843`, etc.).
   - Merkle root verification hash & glowing **A+ ESG Score Gauge**.
